# SatQuery AI — Sample Datasets

This directory provides demo remote-sensing datasets for testing and verification during the SIH 2026 Internal Round.

## Preloaded Demo Scenarios (Embedded in UI)

| Scenario | Input Modality | Sensor / Resolution | Description |
|---|---|---|---|
| **Demo 1: Single VQA** | Single Optical RGB | 0.5m GSD (GeoTIFF) | Coastal seaport facility & transport corridors |
| **Demo 2: Captioning** | Single Optical RGB | High-Res Sensor (PNG) | Scene summary & land-cover composition |
| **Demo 3: Change Analysis** | Bi-Temporal Pair | Sentinel-2 (T1: 2022, T2: 2024) | Urban expansion & canopy clearance detection |
| **Demo 4: Optical + SAR** | Optical + SAR Pair | Sentinel-2 + Sentinel-1 C-Band | Multi-sensor structural & water-body fusion |

These datasets are automatically generated and pre-indexed in the Dashboard under **Quick Demo Datasets**.
